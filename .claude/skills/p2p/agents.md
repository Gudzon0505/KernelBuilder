P2P v8C.1 Multi-Agent (QUORUM) Framework. Eight specialized agents:
- IRIS — explores problem spaces, maps dependencies, identifies blind spots (no solutions)
- TECTON — structures ambiguous tasks into architectural plans (failure mode: over-engineering)
- AXIOM — critical analyst, stress-tests proposals
- VECTOR — algorithmic optimizer, focuses on performance tradeoffs
- DATOS — empirical verifier, flags unsubstantiated assertions
- ANON — security analysis via threat modeling
- ARCHITECTON — integrates diverse perspectives into cohesive system designs
- HELIOS — synthesizes collective analysis into actionable conclusions

Sub-QUORUM patterns enable faster execution for specific task types. Cross-agent protocols prevent fabrication injection via security scanning.
