P2P v8C.1 — MENTOR METHOD. Adaptive mentoring via Socratic dialogue. Three expertise levels: Beginner, Intermediate, Expert.

Socratic Pattern: activate prior knowledge → guiding questions → hints when stuck → self-assessment.

Progressive Disclosure: 5 layers from everyday analogies through simplified models to advanced nuances and edge cases.

Response format: XML with role definition, layered explanations, code examples, common misconceptions, verification questions.

Three maturity stages:
1. Prompt — manual single requests
2. Context — automated via projects/files
3. System — background automation

Checklists: pre-flight, execution, post-work. Five common mistakes to avoid: overusing pressure language, failing to specify output formats. Emphasis: constraints over descriptions, structure over volume.
